A tiny deterministic program that writes the one-sentence defence a house cat gives in the five seconds after knocking a glass off the table to `/output/entry.txt` for make.fun's "Five Seconds to Explain the Glass" bounty. Entry by @oxcaleeev; GitHub owner viseweb3.

Bounty: https://make.fun/bounty/u-po-pu-five-seconds-to-explain-the-glass-934d9949

## Run it

```sh
node main.ts
```

This writes the cat's defence (155 characters, one sentence, one line) to `/output/entry.txt`.
